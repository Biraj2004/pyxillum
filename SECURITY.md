# Security Policy

## Supported Versions

Only the latest release of Pyxillum receives active security updates and vulnerability patches.

| Version | Supported |
| :---: | :---: |
| `0.1.x` | Yes |
| `< 0.1.0` | No |

## Reporting a Vulnerability

If you discover a security vulnerability or potential hardware risk (such as a protocol sequence that could brick or corrupt controller non-volatile memory):

1. **Do NOT open a public issue.**
2. Send an email report to the project maintainers with:
   - Detailed description of the vulnerability or hardware safety risk.
   - Exact steps or byte sequence to reproduce.
   - Affected controller hardware and firmware versions.
3. You will receive an acknowledgment within 48 hours, followed by an assessment and patch timeline.
4. Public disclosure will occur responsibly after a fix is merged.
